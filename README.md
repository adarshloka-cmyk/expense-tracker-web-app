#  Expense Tracker Web App

A modern full-stack expense tracker web application built using React, Firebase Authentication, Firestore Database, and Firebase Hosting.

## Features

- User Authentication
- Add / Edit / Delete Expenses
- Budget Tracking
- Monthly Expense Analytics
- Pie Chart Visualization
- Dark / Light Mode
- PDF Report Export
- Search & Category Filters
- Responsive Modern UI
- Cloud Firestore Database
- Multi-user Expense Isolation

## Tech Stack

- React.js
- Vite
- Firebase Authentication
- Firestore Database
- Firebase Hosting
- Recharts
- jsPDF
